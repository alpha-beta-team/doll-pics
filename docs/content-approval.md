# Public proof and claims approval

Testimonials, team profiles, statistics, awards, and process media start as
unpublished drafts. Publication is a deliberate editorial action, not a seed or
upload default.

## Before publishing

### Testimonials

- Confirm the feedback came from a real Doll Pictures client.
- Record the source privately (for example, a Google review URL or consent message).
- Obtain permission to publish the client name, session context, quote, and portrait.
- Keep the wording faithful to the source; do not invent locations, ratings, likes, or outcomes.
- Remove personal information the client did not approve.

### Team profiles

- Confirm the person is a current team member and approves the displayed name, role, biography, and portrait.
- Upload a real portrait through the CMS media workflow.
- Never publish `localhost`, loopback, stock-person, or placeholder portrait URLs.

### Statistics and awards

- Keep an internal evidence note containing the calculation/source, responsible owner, and as-of date.
- Publish only a defensible figure with an unambiguous label.
- Name and evidence every award; otherwise leave the claim unpublished.
- Recheck time-sensitive figures at least annually.

### Behind-the-scenes media

- Use media showing the actual Doll Pictures team or process.
- Confirm permission from recognizable people.
- Add an accurate title and description.
- Do not present stock footage or staged third-party media as studio activity.

## Release check

1. A second person checks the evidence or consent.
2. Publish the CMS record only after approval.
3. Verify the public API and rendered page.
4. Confirm media returns HTTP 200 from a public HTTPS URL.
5. Unpublish immediately if consent, accuracy, employment status, or media availability changes.
